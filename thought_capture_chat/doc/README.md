## Thought capture chat
is an application where a user can exercise recording their thoughts, conversations with the different personalities that live inside their minds. We all spend a lot of time nowadays on our smartphones, on social media platforms and its become normalised to write text messages to someone. but sometimes, more often that you can imagine, we dont need or want to talk to a person, but we want to express our thoughts in the physical world. Thought Capture Chat allows just that.

## use cases
- im bored and im lying on my bed, my thoughts are loose. i want to record them them down in a conversational way
- im brainstorming an idea about a feature that i want to add to a project. i need to talk to someone about it, but not necessarily talk to a person, but i want to speak about it, layout the details in conversational terms.
- i want to create dialogues for a script im working on on the go withought having to take out my notebook and going through the last bookmark. i want to be able to take out my phone on the bus and start typing whatever strikes me at that moment.
